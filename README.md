📚 RAG Chatbot — Semantic Document Retrieval with LLMs

Built a Retrieval-Augmented Generation (RAG) chatbot that uses vector embeddings to enable semantic document search, significantly improving answer relevance over keyword-based retrieval.

→ Chunked and embedded documents using sentence transformers / OpenAI embeddings
→ Stored vectors in FAISS/Pinecone for efficient similarity search
→ Integrated with LLM for answer synthesis grounded in retrieved context
→ Built UI with Streamlit for interactive querying

Stack: Python · LangChain · FAISS · Streamlit · [LLM used]
